# Contracts

`fungible_token.wasm` is NEAR's official standard fungible token (NEP-141)
example contract, unmodified, taken from
https://github.com/near-examples/FT (commit 6a96a120ad, `res/fungible_token.wasm`).

sha256: 024570509fa82cf25ee2448ab63a8343b3c7ced16b68109d27448beaf4326bbb

It powers **$SABOTEUR** (testnet only), deployed to `token.saboteur.testnet`
by `scripts/setup-saboteur-token.mjs`. No real value.
